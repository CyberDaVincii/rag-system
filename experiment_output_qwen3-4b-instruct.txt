Q: What is a context window?
A: A context window is the segment of text that a language model considers when generating a response. It defines the maximum number of tokens (words or subwords) that the model can use to understand and process the input before producing an output. For example, GPT-2 has a context window of only 1k tokens, meaning it can only consider up to 1,000 tokens of text for its internal processing. The context window determines the scope of the input text that is relevant to each token, and the attention mechanism helps identify which tokens are most relevant to each other within this window.

Q: What is a context window?
A: A context window is the number of tokens that an LLM considers when processing input. It defines the segment of text that is available to the model for context, and within this window, the attention mechanism calculates "soft" weights for each token to determine relevance. For example, in the GPT-2 model, the context window is 1k tokens, meaning the model can process up to 1,000 tokens of input at a time. The context for a given token depends on the model type: in autoregressive models, it is the text before the token; in masked models, it is the text surrounding the token.

Q: Why do large language models hallucinate?
A: Hallucinations in large language models arise partly through memorization of training data combined with extrapolation beyond factual boundaries. Evaluations have shown that models can output verbatim passages from training data when subjected to specific prompting sequences. This results in syntactically fluent text that appears factually sound but is internally inconsistent with training data or factually incorrect.

Q: When was the transformer architecture introduced, and in which paper?
A: The transformer architecture was introduced in 2017 in the paper "Attention Is All You Need."
